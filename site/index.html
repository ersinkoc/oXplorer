OXplorer

A dual-pane file manager for macOS — Finder’s look and feel with Total Commander’s efficiency. Open source.

Download Source on GitHub

Fast

100,000 files list in about a second, first rows in ~20 ms, live updates as things change.

Tabs and dual pane

Tabs in each pane, F5/F6 to copy or move across, compare panes, and your layout comes back.

Finder-friendly

Native icons and menus, Quick Look, Finder tags, a shared clipboard and drag and drop both ways.

Search

Names, file contents (ripgrep’s engine) or Spotlight, with results you can work with like a folder. ⌘K for everything.

Preview

Code with syntax highlighting, Markdown, images, audio and video right next to your files.

Terminal

Your shell in a panel that can follow the folder you’re in — and the folder can follow your cd.

Archives and servers

Browse zip and tar files like folders; SFTP, FTP, WebDAV and S3 in the sidebar.

And more

Git status badges, a disk usage map, batch rename, undo for everything that can be undone, Turkish and English.

Install

Signed builds will be on GitHub Releases and in a Homebrew tap with the first release; until then, build it from source:

git clone https://github.com/ersinkoc/oXplorer
cd oXplorer && pnpm install && pnpm tauri build

macOS 14 or later. Released versions update themselves.
